- # Student Management System

# Database Design

## Tables
1. Students: stores student information.
2. Courses: stores course information.
3. Enrollments: connects students with courses.
4. Results: stores marks and grades.

## Relationships
- One student can have multiple enrollments.
- One course can have multiple enrollments.
- Each enrollment can have one result.
- # requerments

## Objective
To manage student records, courses, enrollments,
marks, and grades using MySQL.

## Functional Requirements
- Add and view student records
- Update and delete student records
- Manage courses and enrollments
- Store student marks and grades
- Generate student result reports
- Search students by ID or name

## Technology
- Database: MySQL
- Language: SQL
- Interface: MySQL Workbench or MySQL command line
